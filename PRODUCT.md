# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Computer-science students and teachers working through the theory of computation (automata,
regular and context-free languages, Turing machines, decidability), on laptops in class or at
home and on phones between classes. Students use it to check exercises and see constructions
run; teachers embed live examples in course pages and set strict-mode assignments.

## Product Purpose

Delta lets you write machines, languages and constructions as code and see them run: draw a DFA
as arrows, state a language in set-builder notation, write the subset construction as its
definition, then test, step through and compare them. Success is a student understanding a
construction by running and changing it, not by reading about it.

## Positioning

A real programming language whose values are the objects of computation theory, with checks that
know what is decidable: an undecidable question is an error before the program runs, with a
bounded check offered instead. Every docs example runs in the browser (the Pad).

## Constraints and assets

- The δ logo (favicon.svg); the Pad at /pad/ is the product's working surface.
