**Numerical answer type.** A DFA reads a binary number most significant bit first and accepts it
when the number is divisible by 5. The empty string is read as 0. How many states does the
minimal such DFA have?

## Solution

Keep the remainder of the number read so far. Reading a bit `b` turns the number `x` into
`2x + b`, so the remainder `r` becomes `(2r + b) mod 5`. That is a DFA with the 5 states
`0, 1, 2, 3, 4`, starting and accepting in `0`.

All 5 are needed: from remainder `r`, appending bits can reach any remainder, and two different
remainders `r ≠ s` give different remainders after the same suffix (multiplying by 2 is
invertible mod 5). So no two states are equivalent.

**Answer: 5.** In general, divisibility by `n` needs at most `n` states, and exactly `n` when `n`
is odd.

## Check it in Delta

The DFA is generated by a function: its states are the numbers `0` to `n - 1`.

```delta
fn divisible_by(n) = dfa {
  alphabet 0, 1
  start  [0]
  accept [0]
  for r ∈ 0..n {
    [r] -0-> [(2*r) % n]
    [r] -1-> [(2*r + 1) % n]
  }
}
let M = minimize(divisible_by(5))
assert M.size == 5
check M accepts "0", "101", "1010", "1111"
check M rejects "1", "11", "110"
```
