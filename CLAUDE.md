# Delta

Programmable automata playground: write the formal tuple of a machine in the Delta DSL, see it
drawn, run it, and convert it using Sipser's own constructions. Live at `delta.nandish.dev`.

The full plan is in `docs/plan/` (start with `README.md`). The current phase is tracked in
`docs/plan/06-ROADMAP-AND-TESTING.md`. Do only the phase you are asked to do.

## Layout

- `crates/delta-core`: models and algorithms (pure Rust, no wasm deps)
- `crates/delta-dsl`: lexer, parser, checker
- `crates/delta-wasm`: wasm-bindgen facade, JSON in / JSON out
- `crates/delta-cli`: native CLI
- `web/`: React 19 + TypeScript strict + Vite + Tailwind v4 (pnpm)
- `web/src/engine/pkg/`: generated by `scripts/build-wasm.sh`, never edit, never commit
- `web/src/engine/generated/`: TS types generated from Rust by `cargo test` (ts-rs), committed

## Rules

- Book-faithful: every algorithm cites its Definition/Theorem/Lemma number in its doc comment.
- "Simple Rust" (03-ARCHITECTURE.md §3.1): index IDs, `Vec`s, owned data, one algorithm per file,
  no `unsafe`, no lifetimes in public types.
- `delta-core` and `delta-dsl` must never panic: `unwrap`, `expect`, `panic!` are denied by Clippy.
  Errors are values (`Result`).
- The reference PDF in the repo root is copyrighted and gitignored. Never commit it.
- All engine calls from the UI go through the Web Worker (`web/src/engine/client.ts`).

## Checks (all must pass before committing)

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
./scripts/build-wasm.sh
./scripts/check-wasm-size.sh          # fails if the .wasm is > 700 KB gzipped
cd web
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e                          # Playwright: phone, tablet, desktop
```
